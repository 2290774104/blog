# nestjs 安装

## 介绍

Nest 是一个用于构建高效，可扩展的 Node.js 服务器端应用程序的框架。它使用渐进式 JavaScript，内置并完全支持 TypeScript

## 安装脚手架

通过 npm 指令全局安装脚手架工具`@nestjs/cli`

```sh
npm i -g @nestjs/cli
```

## 创建项目

`project-name` 为创建项目的名称

```sh
nest new project-name
```
