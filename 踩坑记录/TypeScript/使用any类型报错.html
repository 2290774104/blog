使用 any 类型报错

问题描述

在 ts 使用 any 作为数据类型时出现报错：Unexpected any. Specify a different type.

解决方法

关闭 any 类型的警告，在 .eslintrc.js 文件中找到 rules 添加以下代码

'@typescript-eslint/no-explicit-any': ['off']
